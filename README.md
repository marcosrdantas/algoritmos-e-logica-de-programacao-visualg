# 💻 Lógica de Programação com VisuAlg

Este repositório contém meus códigos e resoluções de exercícios focados na construção de uma base sólida em **Lógica de Programação e Algoritmos**, utilizando a pseudo-linguagem VisuAlg.

## 🚀 Como estou estudando

A "espinha dorsal" deste repositório é o curso de Algoritmos do **Curso em Vídeo** (Prof. Gustavo Guanabara), mas com foco em aprendizado ativo. Minha metodologia inclui:

* **Resolução Antecipada:** Sempre tento resolver os exemplos propostos nas aulas *antes* do professor executar o código no vídeo.
* **Complexidade Adicional:** Costumo pegar os exercícios básicos e aplicar melhorias próprias (como adicionar travas de segurança, menus e validações de dados).
* **Exercícios do PDF:** Resolução das listas de exercícios oficiais do curso.
* **Desafios Externos:** Implementação de lógicas e desafios extras que encontro em outras fontes para complementar os estudos.

## 📁 Tópicos abordados

Durante a evolução dos códigos, você encontrará a aplicação prática de:
* Comandos de Entrada e Saída
* Variáveis e Tipos de Dados
* Operadores Lógicos e Relacionais
* Estruturas Condicionais (`Se... Entao`, `Escolha... Caso`)
* Estruturas de Repetição (`Enquanto`, `Repita... Ate`, `Para`)

## 🛠️ Ferramentas
* **Linguagem:** Portugol / Pseudocódigo
* **Software:** VisuAlg
